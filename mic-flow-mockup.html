Microphone: how it works

The home-screen mic card has two looks, so you can tell at a glance whether the mic is set up. Pressing Play without a setup asks what to do. In the game, the call screen only offers the mic if it was set up; otherwise it is just the big press-and-hold button. Scroll sideways to see all six screens.

The card is grey-ish with a yellow “Not set up yet” tag, and the main button on it says what to do next.
